# Keep Lit

Cup a candle and walk a dark house. Hold to shield the flame; release to let it breathe.

This is a 12-room vertical slice. Procedural placeholder art, no audio yet.

## Play

- Hold the mouse, a touch, Space, or Enter to cup the flame.
- Release in calm rooms so the flame can recover. Cupping also slows your walk.
- If the flame goes out, the run restarts in place almost immediately.

Local preview: `npm install && npm run dev` then open http://127.0.0.1:5175/ (not localhost).
